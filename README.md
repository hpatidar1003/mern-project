# Cyber Attack Map

A simple real-time visualization of cyber attacks using the MERN stack.

## Structure
- `backend/`: Node/Express server using Socket.io to stream events.
- `frontend/`: React app with Globe.gl for visualization.

## Setup

### Backend
1. Go to `backend/`
2. `npm install`
3. `npm start`

### Frontend
1. Go to `frontend/`
2. `npm install`
3. `npm run dev`

The app will be running at the URL provided by Vite.
